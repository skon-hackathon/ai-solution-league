# 박람회 고객 파트너십 강화 출장: 이동 동선 및 시간 계획 가이드

> `Find Your Partner` AI Agent가 박람회 출장의 비즈니스 목표를 이해하고, 고객·파트너 방문 우선순위와 부스 위치를 함께 고려해 실행 가능한 동선과 시간표를 만드는 방법을 정의한다.

## 1. 문서 목적

박람회에서 고객 파트너십을 강화하려는 출장은 많은 부스를 방문하는 것이 목적이 아니다. 핵심 고객과 충분한 대화를 나누고, 적절한 파트너 후보를 만나며, 각 대화에서 다음 행동을 합의하는 것이 중요하다.

따라서 AI Agent는 단순한 최단 경로가 아니라 다음의 비즈니스 성과를 최대화하는 계획을 만들어야 한다.

- 기존 핵심 고객과의 관계 강화
- 진행 중인 협업 과제와 이슈 확인
- 의사결정권자 및 실무 책임자와의 접점 확보
- 신규 파트너 후보 발굴과 협력 가능성 검증
- 후속 미팅, 기술 검토, 제안서 전달 등 다음 행동 합의
- 이동·대기·일정 충돌을 줄여 실제 대화 시간을 확보

이 문서는 프로젝트의 핵심 흐름인 `Understand → Plan → Act → Prepare → Support` 가운데 `Plan`을 중심으로 하되, 캘린더 등록과 현장 재계획까지 연결되는 기준을 제시한다.

## 2. 핵심 계획 원칙

### 2.1 최단 동선보다 비즈니스 성과를 우선한다

가까운 부스만 순서대로 방문하면 이동거리는 짧아지지만 중요한 고객을 놓칠 수 있다. Agent는 방문 가치, 약속 시간, 이동 비용을 함께 평가해야 한다.

```text
좋은 계획
= 높은 가치의 고객 접점 확보
+ 약속 시간 준수
+ 충분한 대화 및 기록 시간
+ 현실적인 이동 동선
+ 현장 변화 대응 여유
```

### 2.2 확정 미팅을 일정의 기준점으로 삼는다

시간이 합의된 고객 미팅은 먼저 고정한다. 나머지 부스 방문은 고정 미팅 사이의 가용 시간에 배치한다.

- `고정 일정`: 사전 확정 고객 미팅, 세미나, 고객 오찬, 출발·복귀 시간
- `준고정 일정`: 담당자 재실 시간이 정해진 부스, 우선순위가 높은 파트너 미팅
- `유동 일정`: 일반 부스 방문, 시장 조사, 제품 데모 관람
- `대체 일정`: 취소·지연 시 같은 구역에서 즉시 방문할 후보

### 2.3 중요한 대화 뒤에는 기록 시간을 보호한다

핵심 고객과의 대화 직후 다음 부스로 이동하면 중요한 합의와 후속 조치가 누락될 수 있다. P0·P1 미팅 뒤에는 최소 10분의 기록 및 이동 준비 시간을 둔다.

### 2.4 계획을 100% 채우지 않는다

현장에서는 입장 대기, 부스 혼잡, 미팅 연장, 길 찾기 실패가 발생한다. 전체 가용 시간의 65~75%만 확정 일정으로 채우고 나머지는 이동·기록·회복·돌발상황에 사용한다.

### 2.5 모든 추천에는 이유와 신뢰도를 제시한다

Agent는 “A사 다음 B사를 방문하세요”라고만 안내하지 않는다. 고객 관계, 협력 가능성, 부스 거리, 담당자 재실 시간 등 판단 근거와 데이터의 최신성을 함께 보여준다.

## 3. Agent가 수집해야 할 입력 정보

### 3.1 출장 및 행사 정보

| 항목 | 필수 여부 | 예시 |
|---|---:|---|
| 출장 목적 | 필수 | 기존 고객 교류 및 파트너십 강화 |
| 행사명·장소·운영시간 | 필수 | InterBattery, 코엑스, 10:00~17:00 |
| 출장자 출발지·복귀 제한시간 | 필수 | 대전 출발, 19:30 이전 복귀 |
| 참가자 | 권장 | 영업 1명, 기술 담당 1명 |
| 식사·휴식 제약 | 권장 | 12:00 고객 오찬 |
| 이동·접근성 제약 | 권장 | 장시간 보행 제한, 휠체어 동선 필요 |

### 3.2 고객 및 파트너 정보

- 기존 고객 등급과 최근 거래·협업 현황
- 최근 미팅 내용 및 미완료 Action Item
- 고객별 관심 제품, 기술, 이슈
- 이번 출장에서 확인할 질문과 제안 가능한 협력안
- 참석 예정 담당자와 의사결정 영향력
- 담당자 재실 시간 및 사전 약속 여부
- 잠재 파트너의 사업 연관성, 기술 적합성, 최근 동향

### 3.3 전시장 및 이동 정보

- 홀, 층, 출입구, 부스 번호와 좌표
- 홀 간 이동 통로, 에스컬레이터, 엘리베이터 위치
- 예상 도보 시간과 혼잡 시간대
- 등록 데스크, 라운지, 회의실, 식당 위치
- 세미나 시간과 장소
- 주차장·지하철역·택시 승강장에서 행사장까지의 접근 시간

### 3.4 실시간 정보

- 현장 체크인 완료 시각
- 현재 위치
- 부스 혼잡도 및 예상 대기시간
- 담당자 도착·지연·취소 알림
- 미팅 실제 시작·종료 시각
- 교통 지연과 행사장 운영 변경

### 3.5 정보가 부족할 때의 처리

Agent는 확인되지 않은 정보를 사실처럼 채우지 않는다.

1. 일정 성립에 꼭 필요한 정보만 사용자에게 먼저 확인한다.
2. 부스 위치처럼 외부 데이터로 확인 가능한 항목은 행사 DB나 공식 안내도를 조회한다.
3. 확인되지 않은 항목은 `가정`, `확인 필요`, `정보 없음`으로 구분한다.
4. 위치를 모르는 기업은 고정 경로에 넣지 않고 유동 후보 목록에 둔다.
5. 데이터의 출처와 확인 시각을 계획 결과에 기록한다.

## 4. 전체 계획 Workflow

```text
출장 목적과 제약 이해
        ↓
고객·파트너 후보 조사
        ↓
방문 가치 및 우선순위 계산
        ↓
확정 미팅을 시간표에 고정
        ↓
부스 간 이동시간 행렬 생성
        ↓
구역별 후보 묶음 생성
        ↓
고정 일정 사이에 유동 방문 배치
        ↓
기록·이동·혼잡 Buffer 삽입
        ↓
Plan A와 대체 후보 생성
        ↓
캘린더·동선 지도·Meeting Brief 생성
        ↓
현장 상황에 따라 재계획
```

## 5. 방문 우선순위 결정

### 5.1 우선순위 등급

| 등급 | 의미 | 계획 방식 |
|---|---|---|
| P0 | 시간이 확정된 핵심 고객 미팅 | 반드시 고정, 앞뒤 Buffer 확보 |
| P1 | 관계 강화가 필요한 기존 핵심 고객 | 당일 필수 방문, 충분한 대화시간 배정 |
| P2 | 협력 가능성이 높은 신규·기존 파트너 | P0·P1 사이에 우선 배치 |
| P3 | 신규 사업 기회 또는 기술 탐색 대상 | 가까운 구역의 빈 시간에 배치 |
| P4 | 경쟁·시장 동향 파악 대상 | 시간이 남을 때 짧게 방문하거나 자료 수집으로 대체 |

### 5.2 비즈니스 가치 점수

각 항목을 0~5점으로 평가하고 100점으로 환산한다. 가중치는 출장 목적에 따라 조정할 수 있다.

| 평가 항목 | 기본 가중치 | 판단 질문 |
|---|---:|---|
| 기존 관계 중요도 | 30% | 핵심 고객인가, 최근 관계 관리가 필요한가? |
| 파트너십·사업 기회 | 25% | 구체적인 공동 과제나 매출 기회로 이어질 수 있는가? |
| 이번 만남의 시급성 | 15% | 지금 만나지 않으면 놓칠 이슈나 일정이 있는가? |
| 핵심 인물 접점 | 15% | 의사결정권자 또는 핵심 실무자가 현장에 있는가? |
| 후속 행동 가능성 | 10% | PoC, 기술 미팅, 제안 요청 등 다음 단계가 명확한가? |
| 전략·시장 정보 가치 | 5% | 경쟁·기술 동향 파악에 중요한가? |

```text
BusinessValue
= 관계 중요도 × 0.30
+ 파트너십 기회 × 0.25
+ 시급성 × 0.15
+ 핵심 인물 접점 × 0.15
+ 후속 행동 가능성 × 0.10
+ 전략 정보 가치 × 0.05
```

확정 미팅 여부는 점수와 별도로 `Hard Constraint`로 처리한다. 즉, 점수가 조금 낮더라도 이미 약속된 미팅을 다른 일반 방문으로 대체하지 않는다.

### 5.3 데이터 신뢰도 반영

점수가 높아도 담당자 재실 여부나 부스 위치가 오래된 정보라면 일정 실패 가능성이 크다.

```text
실행 우선도 = BusinessValue × 데이터 신뢰도 × 미팅 성사 가능성
```

예를 들어 BusinessValue가 90점이어도 담당자 참석 여부가 확인되지 않았다면 `사전 확인 필요` 상태로 표시하고, 동시에 같은 구역의 대체 방문 후보를 준비한다.

## 6. 방문 시간 산정

### 6.1 방문 유형별 기본 시간

| 방문 유형 | 권장 체류시간 | 포함할 활동 |
|---|---:|---|
| P0 핵심 고객 확정 미팅 | 40~60분 | 현황 확인, 핵심 논의, 협력안, 다음 행동 합의 |
| P1 기존 고객 관계 강화 | 30~45분 | 관계 점검, 이슈 확인, 후속 미팅 제안 |
| P2 잠재 파트너 검증 | 20~30분 | 적합성 확인, 상호 니즈 파악, 연락처·후속 단계 확보 |
| P3 신규 기회 탐색 | 15~20분 | 핵심 제품 확인, 담당자 연결, 추가 자료 요청 |
| P4 시장 조사 | 5~15분 | 전시 내용 확인, 자료 수집, 짧은 질의 |

### 6.2 미팅 시간의 구성

기존 고객과의 35분 미팅은 다음처럼 구성할 수 있다.

```text
인사 및 관계 형성            5분
최근 현황·관심사 확인        10분
협업 이슈·제안 논의          12분
다음 행동과 담당자 합의       5분
현장 메모                    3분
```

Agent는 Meeting Brief의 아젠다 수, 참석자 수, 통역 필요 여부에 따라 시간을 늘리거나 줄인다.

### 6.3 이동 및 Buffer 기준

- 같은 홀·인접 구역: 지도 예상시간 + 최소 5분
- 다른 홀 또는 층: 지도 예상시간 + 최소 10분
- P0·P1 미팅 전: 10분의 도착 여유
- P0·P1 미팅 후: 10분의 메모 및 Action Item 정리
- 점심 전후, 개장 직후, 폐장 직전: 혼잡 계수 추가
- 하루 일정 중 최소 한 번 20~30분의 회복 Buffer 확보

지도 데이터가 없을 때는 직선거리로 시간을 확정하지 않고 보수적인 기본값을 사용한 뒤 `현장 안내도 확인 필요`로 표시한다.

## 7. 동선 최적화 방법

### 7.1 Hard Constraint와 Soft Constraint를 분리한다

반드시 지켜야 하는 `Hard Constraint`:

- 행사 운영시간
- 출장자의 도착·복귀 시간
- 확정된 고객 미팅 시간
- 각 미팅의 최소 체류시간
- 부스 간 최소 이동시간
- 접근성·보안·출입 제한

가능하면 만족해야 하는 `Soft Constraint`:

- 총 도보거리와 홀 간 이동 최소화
- 우선순위가 높은 기업의 방문 수 최대화
- 대기시간과 역주행 최소화
- 점심·휴식시간 확보
- 같은 업종·협력 주제의 방문을 연속 배치
- 중요한 미팅을 집중력이 높은 시간대에 배치

### 7.2 구역별로 후보를 묶는다

Agent는 부스를 홀·층·통로 기준으로 묶어 `Zone Cluster`를 만든다. 같은 구역의 P1·P2 후보는 가급적 연속으로 배치하되, 가까운 부스를 방문한다는 이유만으로 낮은 가치의 기업을 핵심 고객보다 앞세우지 않는다.

```text
오전: Hall A의 핵심 고객·파트너
점심: 고객 오찬 또는 네트워킹
오후: Hall B의 확정 미팅·신규 파트너
마감 전: 가까운 유동 후보 또는 후속 대화
```

### 7.3 고정 일정 사이에 후보를 삽입한다

고정 미팅 사이의 빈 시간마다 다음 값을 계산한다.

```text
삽입 효율
= 실행 우선도
÷ (방문시간 + 추가 이동시간 + 예상 대기시간)
```

단, 단순히 효율이 높다는 이유로 핵심 고객 방문시간을 줄이지 않는다. 시간이 부족하면 가장 낮은 `한계 비즈니스 가치`를 가진 유동 방문부터 대체 목록으로 이동한다.

### 7.4 최적화 목표

Agent의 목적함수는 다음 관계를 따른다.

```text
최대화:
  방문한 기업의 총 비즈니스 가치
  + 확정 미팅 준수율
  + 후속 행동 확보 가능성

최소화:
  이동시간
  + 대기시간
  + 일정 지각 위험
  + 같은 구역 재방문
  + 과도한 일정 밀도
```

기술적으로는 `시간창이 있는 경로 최적화` 문제로 다룰 수 있다. MVP에서는 완전한 최적해보다 이해하기 쉬운 규칙 기반 삽입 방식으로 시작하고, 이후 지도 API의 이동시간 행렬과 최적화 Solver를 연결한다.

## 8. 시간 계획 규칙

### 8.1 권장 시간 배분

| 용도 | 권장 비율 |
|---|---:|
| P0·P1 핵심 고객 | 35~45% |
| P2 파트너 후보 | 20~25% |
| P3·P4 신규 기회 및 시장 조사 | 10~15% |
| 이동·대기 | 10~15% |
| 기록·휴식·비상 Buffer | 15~20% |

위 비율은 기본값이다. 이미 많은 고객 미팅이 확정됐다면 신규 기업 탐색 비중을 줄이고, 신규 파트너 발굴이 주목적이라면 P2 비중을 높인다.

### 8.2 시간대별 배치 원칙

- 개장 직후: 혼잡이 적으므로 핵심 부스 또는 인기 부스 우선 방문
- 오전 집중 시간: P0·P1의 전략적 대화 배치
- 점심 시간: 고객 오찬, 관계 형성, 담당자 부재를 고려한 휴식
- 오후 초반: P2 파트너 검증과 제품 데모
- 오후 후반: 확정 미팅, 미방문 핵심 후보, 짧은 후속 대화
- 폐장 30분 전: 장거리 이동을 시작하지 않고 기록·후속 조치 정리

### 8.3 과밀 일정 방지 규칙

- 연속 세 미팅 후에는 최소 15분 Buffer를 둔다.
- 한 시간 안에 서로 다른 홀의 미팅 두 개를 배치하지 않는다.
- 미팅 종료와 다음 미팅 시작이 같다면 유효하지 않은 계획으로 처리한다.
- P0 미팅은 직전 유동 방문이 지연돼도 영향을 받지 않도록 보호한다.
- 식사나 휴식을 삭제해야만 성립하는 계획은 사용자에게 추천하지 않는다.

## 9. Agent가 제공해야 할 계획 결과

### 9.1 한눈에 보는 요약

- 출장의 핵심 성공 목표
- 필수 고객과 파트너 후보 수
- 확정 미팅 수와 유동 방문 수
- 예상 총 대화시간, 이동시간, Buffer
- 계획의 주요 가정과 확인이 필요한 항목

### 9.2 시간표

| 시간 | 활동 | 위치 | 우선순위 | 목적 | 다음 행동 목표 |
|---|---|---|---:|---|---|
| 10:00~10:40 | A기업 고객 미팅 | Hall A, A-120 | P0 | 기존 협업 점검 | 기술 후속 미팅 확정 |
| 10:40~10:50 | 기록 및 이동 | A-120 → A-310 | - | Action Item 기록 | 담당자·기한 저장 |
| 10:50~11:20 | B기업 파트너 미팅 | Hall A, A-310 | P2 | 공동 PoC 가능성 확인 | NDA 검토 담당자 확보 |

각 일정에는 `왜 이 시간과 순서인지`를 한 문장으로 설명한다.

### 9.3 동선 지도와 구간 안내

- 출입구부터 첫 미팅까지의 경로
- 부스별 방문 순서
- 구간별 예상 이동시간
- 층·홀 변경 지점
- 화장실, 라운지, 회의실 등 회복 지점
- 이동이 긴 구간과 지각 위험 구간

### 9.4 기업별 Meeting Card

- 회사와 당사의 관계
- 최근 동향과 이번 만남의 목적
- 확인할 질문 3개
- 제안할 협력 포인트 1~2개
- 반드시 합의할 다음 행동
- 담당자와 연락 수단
- 미팅 종료 후 기록할 항목

### 9.5 대체 방문 목록

| 대체 후보 | 위치 | 필요시간 | 대체 조건 | 방문 목표 |
|---|---|---:|---|---|
| G기업 | Hall A, A-330 | 15분 | B기업 담당자 부재 | 기술 담당자 연결 |
| H기업 | Hall B, B-205 | 20분 | D기업 미팅 취소 | 제품 데모 및 후속 미팅 요청 |

대체 후보는 원래 일정과 같은 구역에 있는 기업을 우선하여 재계획 비용을 줄인다.

## 10. 가상 일정 예시

다음은 프로젝트의 데모 요청인 “서울 코엑스 박람회에서 고객 교류와 파트너십 강화”를 가정한 예시다. 기업명, 부스, 시간은 계획 방식 설명을 위한 가상 데이터다.

### 10.1 Agent가 이해한 목표

```text
1순위: 기존 핵심 고객과의 관계 강화
2순위: 구체적인 공동 과제가 가능한 파트너 발굴
3순위: 후속 미팅과 담당자가 명확한 Action Item 확보
4순위: 배터리 산업 및 경쟁 동향 파악
```

### 10.2 계획안

| 시간 | 일정 | 위치 | 구분 | 계획 이유 |
|---|---|---|---|---|
| 09:30~10:00 | 도착·등록·당일 일정 확인 | 코엑스 입구 | 준비 | 등록 지연과 지도 확인 시간 확보 |
| 10:00~10:40 | A기업 핵심 고객 미팅 | Hall A, A-120 | P0 | 확정 미팅이며 기존 협업 이슈가 있음 |
| 10:40~10:55 | 메모·이동 | A-120 → A-310 | Buffer | Action Item 기록 및 다음 미팅 준비 |
| 10:55~11:25 | B기업 파트너 검증 | Hall A, A-310 | P2 | A기업과 같은 구역이며 공동 PoC 가능성이 높음 |
| 11:25~11:45 | 같은 구역 유동 방문 | Hall A | P3 | 지연 시 삭제 가능한 일정 |
| 11:45~12:00 | 이동 | Hall A → 회의실 | Buffer | 고객 오찬 지각 방지 |
| 12:00~13:00 | C기업 고객 오찬 | 회의실 | P0 | 관계 형성과 중장기 협력 논의 |
| 13:00~13:20 | 기록·휴식·Hall B 이동 | Hall B | Buffer | 오전 Action Item 정리 및 회복 |
| 13:20~13:50 | D기업 신규 파트너 미팅 | Hall B, B-210 | P2 | 기술 보완성이 높고 담당자 재실 확인 |
| 13:50~14:15 | E기업 제품 데모 | Hall B, B-260 | P3 | D기업 인접 부스이며 신사업 탐색 가치가 있음 |
| 14:15~14:35 | 유동 Buffer | Hall B 라운지 | Buffer | 혼잡·미팅 연장 흡수, 필요 시 대체 방문 |
| 14:35~15:15 | F기업 기존 고객 미팅 | Hall B, B-430 | P1 | 최근 협업이 정체되어 관계 점검 필요 |
| 15:15~15:30 | 메모·후속 일정 확인 | Hall B | Buffer | 후속 미팅·담당자·기한 확정 |
| 15:30~16:00 | 미방문 P2 또는 현장 추천 기업 | 가까운 구역 | 유동 | 당일 인사이트에 따라 Agent가 선택 |
| 16:00~16:30 | 핵심 부스 재방문·자료 회수 | 가까운 구역 | 유동 | 담당자 부재 또는 미완료 질문 보완 |
| 16:30~17:00 | 당일 결과 정리·복귀 준비 | 라운지 | 마감 | Action Item 누락 방지 및 복귀 시간 보호 |

### 10.3 추천 동선

```text
입구
→ A기업(P0)
→ B기업(P2)
→ Hall A 유동 후보
→ C기업 고객 오찬(P0)
→ Hall B 이동
→ D기업(P2)
→ E기업(P3)
→ Hall B 라운지
→ F기업(P1)
→ 가까운 대체 후보
→ 결과 정리 및 복귀
```

이 계획은 A기업과 C기업의 확정 일정을 보호하면서 같은 홀의 후보를 묶고, 오후에는 Hall B에서 역주행 없이 이동하도록 설계한다. 유동 일정 두 개와 Buffer를 남겨 현장 변화에도 핵심 고객 일정이 밀리지 않게 한다.

## 11. 출장 중 실시간 재계획

### 11.1 재계획 Trigger

다음 상황이 발생하면 Agent는 남은 일정만 다시 계산한다.

- 현재 일정이 10분 이상 지연
- P0·P1 담당자의 일정 변경 또는 취소
- 부스 대기시간이 계획보다 15분 이상 증가
- 출장자의 위치가 계획 경로에서 크게 벗어남
- 새로운 고가치 고객·파트너의 현장 미팅 제안
- 복귀 교통편 지연·변경 또는 행사 조기 종료

### 11.2 재계획 우선순위

```text
1. 이미 확정된 P0 미팅과 복귀 제한시간 보호
2. 진행 중인 중요한 대화의 품질 보호
3. 같은 구역의 대체 후보로 교체
4. P3·P4 방문 축소 또는 삭제
5. P1·P2 일정 변경 시 사용자에게 영향과 선택지 제시
```

### 11.3 사용자 안내 형식

```text
현재 B기업 미팅이 15분 연장되어 14:35 F기업 미팅에 지각할 위험이 있습니다.

추천 변경:
- E기업 제품 데모를 오늘의 대체 목록으로 이동
- Hall B 라운지 Buffer를 20분에서 10분으로 조정
- F기업 미팅은 기존 14:35 시작 유지

영향:
- 핵심 고객 미팅 영향 없음
- 예상 도보시간 8분 감소
- P3 방문 1건 감소
```

Agent는 변경 결과만 알리지 않고 변경 이유, 포기한 일정, 핵심 목표에 미치는 영향을 함께 설명해야 한다.

## 12. 프로젝트 Agent 구조와 역할 분담

| Agent | 박람회 동선·시간 계획 역할 |
|---|---|
| Supervisor Agent | 출장 목표 유지, Agent 간 결과 통합, 사용자 확인이 필요한 결정 관리 |
| Research Agent | 참가기업, 고객 관계, 최근 동향, 담당자, 부스 위치와 운영시간 수집 |
| Business Consulting Agent | 기업별 비즈니스 가치, 파트너십 가능성, Meeting Brief와 다음 행동 정의 |
| Travel Planning Agent | 이동시간 행렬, 고정 일정, 구역 묶음, 동선·Buffer·대체 계획 생성 |
| Action Agent | 미팅·이동 Block의 캘린더 등록, Reminder 설정, 승인 후 예약·외부 연락 실행 |
| Support Agent | 현재 위치·지연·취소 감지, 남은 일정 재계획, 현장 알림 제공 |
| Report Generator | 시간표, 동선 지도, Meeting Card, 체크리스트와 출장 Brief 생성 |

### Tool 연결

- 행사·박람회 DB: 참가기업, 부스, 세미나, 운영시간
- 사내 고객·파트너 DB: 관계 등급, 매출·협업, 과거 미팅, Action Item
- 기업·뉴스 검색: 최근 동향과 협력 신호
- 지도·경로 API: 출입구와 부스 간 이동시간 행렬
- Calendar API: 확정 미팅, 이동, Buffer, Reminder 등록
- 교통 API: 행사장 도착과 복귀의 외부 이동 제약 계산
- 문서 생성 Engine: 최종 Brief와 현장용 요약 생성

외부 고객에게 미팅 요청을 보내거나 기존 약속을 변경하는 행위는 Agent가 초안을 만들되 사용자 승인 후 실행하도록 한다.

## 14. MVP 구현 제안

해커톤 MVP에서는 다음 순서로 구현한다.

1. 행사·고객·부스·미팅 정보를 고정 JSON 데이터로 준비한다.
2. 고객 관계와 파트너십 가능성을 이용해 방문 점수를 계산한다.
3. 확정 미팅을 먼저 배치한다.
4. 부스 좌표로 이동시간 행렬을 만든다.
5. 고정 미팅 사이에 점수 대비 소요시간이 높은 후보를 삽입한다.
6. P0·P1 전후 Buffer와 식사·복귀 제한을 적용한다.
7. 계획 결과, 선택 이유, 제외된 후보, Plan B를 화면에 표시한다.
8. “미팅 20분 지연” 버튼으로 남은 일정이 재계획되는 Demo를 제공한다.

MVP의 핵심은 복잡한 최적화 알고리즘 자체보다 다음 Agent Experience를 명확히 보여주는 것이다.

```text
출장 목적 이해
→ 고객·파트너 가치 판단
→ 시간과 위치를 반영한 일정 생성
→ 판단 이유 설명
→ 현장 변화에 맞춰 재계획
```

## 15. 품질 검증 기준과 KPI

### 15.1 계획 유효성 검증

- 행사 운영시간 밖의 일정이 없는가?
- 확정 미팅과 다른 일정이 겹치지 않는가?
- 모든 연속 일정 사이에 실제 이동 가능한 시간이 있는가?
- P0·P1 미팅 전후 Buffer가 있는가?
- 도착·복귀 교통편 제한을 위반하지 않는가?
- 같은 홀을 불필요하게 왕복하지 않는가?
- 일정 변경 시 삭제된 방문과 영향을 설명하는가?
- 모든 기업·부스 정보에 출처와 확인 시각이 있는가?

### 15.2 성과 KPI

| 구분 | KPI 예시 |
|---|---|
| 핵심 고객 커버리지 | 계획된 P0·P1 중 실제 만난 비율 |
| 시간 준수 | 확정 미팅 정시 도착률 |
| 관계 강화 성과 | 후속 미팅·공동 과제·제안 요청 확보 건수 |
| 파트너 발굴 성과 | 유효 파트너 후보 및 담당자 연결 건수 |
| 동선 효율 | 총 이동시간, 불필요한 홀 재방문 횟수 |
| 계획 복원력 | 현장 변경 후 핵심 일정 유지율 |
| 기록 품질 | 미팅별 Action Item의 담당자·기한 완성률 |
| 사용자 신뢰 | 추천 이유의 유용성 및 수동 수정률 |

## 16. 최종 출력 Checklist

Agent는 출발 전 사용자에게 최소한 다음을 제공한다.

- [ ] 출장 목표와 당일 성공 기준
- [ ] 확정 미팅 및 필수 방문 기업
- [ ] 시간대별 일정과 이동시간
- [ ] 부스 순서가 표시된 동선 지도
- [ ] 기업별 방문 이유와 Meeting Card
- [ ] P0·P1 미팅 전후 Buffer
- [ ] 같은 구역의 대체 방문 후보
- [ ] 점심·휴식·복귀 시간
- [ ] 데이터 출처, 확인 시각, 불확실한 가정
- [ ] 일정 지연·취소 시 재계획 기준
- [ ] 미팅별로 확보해야 할 다음 행동

> 최종적으로 좋은 박람회 계획은 “몇 개 부스를 방문했는가”가 아니라 “어떤 고객과 어떤 대화를 나누고, 어떤 파트너십의 다음 단계를 확보했는가”로 평가해야 한다.
